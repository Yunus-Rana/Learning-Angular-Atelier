Signal basics

Signals hold reactive values in your component. Read them in the template and update them to see the view respond.

Writable signal string
#

Employee mobile

{{ empMobileNo() }}

The displayed number comes directly from the signal.

Writable signal boolean

Employee status

{{ isActive() ? 'Active' : 'Inactive' }} {{ isActive() ? 'Ready to go' : 'Currently unavailable' }}

Call the signal to read its current value.

Writable signal string array
